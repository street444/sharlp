# ShaRlpSMP — сайт Minecraft Java SMP

Статичний сайт (HTML/CSS/JS) для GitHub Pages. Покупки відбуваються в Discord (власник: `artem4340036`), сайт **не приймає платежі** і не показує фальшивих підтверджень оплати.

## Запуск на GitHub Pages
1. Створіть репозиторій і завантажте всі файли з цієї папки (включно з `.nojekyll`).
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. Через хвилину сайт буде на `https://<ваш-нік>.github.io/<репозиторій>/`.

## Як змінювати товари, ціни, правила, новини
Усе редагується в одному файлі `js/data.js`: IP, Discord, товари (`price: null` = «Ціну уточнюйте»), промокоди, новини, правила. Після змін зробіть commit — сайт оновиться.

## Чого тут немає (і чому)
GitHub Pages — це лише статика, тому немає акаунтів з паролями, серверної адмін-панелі, карткових платежів і автовидачі в Minecraft (Aternos не дає для цього API). Тому покупка й видача — вручну через Discord. «Мої замовлення» зберігаються лише в браузері користувача.
Промокоди перевіряються на боці браузера, тож остаточну знижку підтверджуєте ви в Discord.
